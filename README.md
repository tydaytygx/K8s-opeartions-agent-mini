# K8s-opeartions-agent-mini

一个真的很小的K8s运维agent，使用本地运行的小模型，即使只有CPU也能勉强运行。

A really mini agent for operators of K8s, using local-run small model.

请不要在生产环境中使用！

Please DO NOT USE IT ON PRODUCTION ENVIRONMENT!

# 如何运行 | How To Run
```
pip install -r requirements.txt
```
```
# Linux
python3 k8s_agent_mini.py

# Windows
python k8s_agent_mini.py
```
